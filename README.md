# Demo_Websiter-workshop

## Vardhan Woodcraft — Fine Carpentry & Modern Wooden Interiors

A premium, fully responsive bespoke website built for master carpenters and interior woodwork contractors.

### 🌟 Features
- **Projects Gallery**: Filterable showcase (*Modular Kitchens, Wardrobes, Custom Furniture, Doors, Wall Panelling*) with technical specification modals.
- **Interactive Cost Estimator**: Real-time pricing calculator based on woodwork type, surface area, timber species, hardware, and polish.
- **Instant Quote & Voucher Generator**: Complete quote request form that generates an estimate voucher with unique reference ID, print/PDF layout, and direct one-click WhatsApp chat integration.
- **Artisan Dark / Light Theme**: Dynamic toggle with persistence in `localStorage`.
- **Timber & Material Guide**: Educational comparison for Teak (Sagwan), Sheesham, Marine BWP 710 Plywood, and Oak Veneers.
- **Mobile Responsive**: Optimized across all viewports and devices.

### 🛠️ Built With
- Pure Semantic HTML5
- Vanilla CSS3 (Custom Design System, Glassmorphism, Micro-animations)
- Vanilla JavaScript (Modular ES6 Architecture)

### 🚀 Running Locally
Open `index.html` in any modern web browser or run:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080/`.
